# HardStop Browser Extension Privacy Policy

**Effective date: August 26, 2026**  
**Last updated: August 26, 2026**

HardStop ("HardStop," "we," "us," or "our") provides a browser extension designed to help users block access to gambling-related websites and support their personal recovery goals.

This Privacy Policy explains how the HardStop browser extension accesses, processes, stores, uses, and protects information. It applies specifically to the HardStop browser extension. The HardStop desktop application or a future HardStop website may have additional privacy terms if they collect or process information separately.

By installing or using the HardStop browser extension, you acknowledge the practices described in this Privacy Policy.

## 1. HardStop's purpose

The single purpose of the HardStop browser extension is to help users avoid online gambling by identifying and blocking access to gambling-related websites.

Depending on the version installed and the settings selected by the user, HardStop may:

- Compare website addresses against a gambling-domain block list.
- Block recognized gambling, casino, sportsbook, betting, sweepstakes-casino, and similar websites.
- Redirect blocked navigation to a HardStop warning or blocked page.
- Save protection settings and lock periods.
- Display whether protection is active.
- Communicate with the locally installed HardStop desktop application.
- Maintain protection settings between browser sessions.

HardStop is a self-help and harm-reduction tool. It is not medical treatment, professional counseling, financial advice, or a guarantee that every gambling-related website will be detected or blocked.

## 2. Information processed by the extension

### Website addresses and navigation information

HardStop must examine the addresses of websites that the user attempts to visit to determine whether they match a gambling-related blocking rule.

This processing may include:

- Website domain names.
- Website URLs.
- Navigation and redirect events.
- Whether a HardStop blocking rule matched a website.
- The browser tab in which blocked navigation occurred.

This information is used only to operate the website-blocking features, display the blocked-page notice, confirm that protection is working, and troubleshoot blocking rules.

HardStop does not use website addresses to create advertising profiles. HardStop does not sell browsing information. Website matching and blocking are performed locally within the user's browser unless this policy is updated to disclose a change.

### Protection settings

HardStop may store information necessary to maintain the user's selected protection settings, including:

- Whether protection is active.
- The selected lock or protection duration.
- The scheduled ending time of a protection period.
- Block-list settings and preferences.
- Extension configuration settings.
- Information needed to synchronize protection with the HardStop desktop application.
- Limited technical information needed to maintain accurate protection status.

These settings are generally stored locally using the browser's extension-storage system.

### Communication with the HardStop desktop application

If the HardStop desktop application is installed, the browser extension may use the browser's native-messaging feature to communicate with it.

This communication may include:

- Protection activation status.
- Approved configuration settings.
- Lock duration and remaining protection time.
- Requests to enable or confirm protection.
- Technical messages necessary to verify that the desktop application and browser extension are connected.

Native messaging is limited to communication between the HardStop browser extension and the authorized HardStop desktop application installed on the user's device.

### Technical and diagnostic information

HardStop may process limited technical information necessary to provide its functionality, such as:

- Whether a blocking rule was triggered.
- Whether the extension and desktop application are connected.
- Whether a scheduled protection check occurred.
- Extension configuration or version information.
- Error information generated while operating the extension.

HardStop does not use this information for advertising or unrelated user profiling.

## 3. Browser permissions

HardStop requests permissions needed to provide its website-blocking and protection features.

### declarativeNetRequest

This permission allows HardStop to apply rules that block requests to recognized gambling-related websites.

### declarativeNetRequestFeedback

This permission may be used to confirm that a blocking rule matched and to provide accurate protection status or troubleshooting information.

### tabs

This permission allows HardStop to identify when a browser tab attempts to access a blocked gambling website and to redirect or replace that tab with the HardStop blocked-page notice.

### webNavigation

This permission allows HardStop to detect navigation and redirects to gambling-related websites so protection can be applied consistently.

### storage

This permission allows HardStop to store protection settings, activation status, lock duration, block-list preferences, and necessary configuration information.

### alarms

This permission allows HardStop to perform scheduled checks related to protection periods and keep time-based lock information accurate when the browser has been inactive, closed, or restarted.

### nativeMessaging

This permission allows the extension to communicate with the locally installed HardStop desktop application and synchronize approved protection settings.

### Host permissions

Host permissions allow HardStop to evaluate website addresses and apply blocking rules across websites. Broad host access may be necessary because gambling services operate across many domains and may introduce or redirect users to additional domains.

HardStop does not use host permissions to inject advertising, collect passwords, read private messages, or sell browsing activity.

## 4. How information is used

HardStop uses information processed by the extension only to:

- Identify and block gambling-related websites.
- Redirect users away from blocked content.
- Display protection status.
- Maintain selected settings between browser sessions.
- Operate time-based protection periods.
- Synchronize approved settings with the HardStop desktop application.
- Maintain, secure, debug, and improve the extension's blocking functions.
- Respond to support or privacy requests initiated by the user.
- Comply with applicable legal requirements.

HardStop does not use extension data for credit decisions, insurance decisions, employment decisions, targeted advertising, or unrelated behavioral profiling.

## 5. Information HardStop does not intentionally collect

The HardStop browser extension is not designed to intentionally collect:

- Passwords or authentication credentials.
- Credit or debit card numbers.
- Bank account information.
- Social Security numbers or government identification numbers.
- Private emails or private messages.
- Health records.
- Precise GPS location.
- Contacts or address books.
- Keystrokes entered on websites.
- Files stored on the user's computer.
- General browsing histories for advertising purposes.

A website address may be examined when required to determine whether it matches a gambling-blocking rule. This limited processing does not grant permission to use the user's browsing activity for unrelated purposes.

## 6. Storage and retention

Protection preferences and extension configuration are generally stored locally in the user's browser or device.

Locally stored information may remain until:

- The user changes or clears the settings.
- The extension removes information that is no longer needed.
- The extension is uninstalled.
- The browser's extension data is cleared.
- The information is replaced during an extension update.

Some HardStop protections may be intentionally designed to resist casual changes during an active lock period. However, HardStop will not represent a protection as technically irreversible unless that statement is accurate.

If a user contacts HardStop for support, we may retain the information voluntarily included in that communication for as long as reasonably necessary to respond, maintain appropriate records, prevent abuse, and comply with legal obligations.

## 7. Data sharing and disclosure

HardStop does not sell or rent personal information.

HardStop does not share extension data with advertising networks or data brokers.

Information may be disclosed only when reasonably necessary:

- To provide a service specifically requested by the user.
- To communicate with the authorized HardStop desktop application installed on the user's device.
- To work with service providers that help operate HardStop, provided they are limited to appropriate uses of the information.
- To investigate fraud, abuse, security threats, or violations of applicable terms.
- To comply with a valid legal obligation, court order, or government request.
- To protect the rights, safety, and security of users, HardStop, or others.
- In connection with a merger, acquisition, financing, reorganization, or sale of assets, subject to appropriate privacy protections and notice where required.

HardStop will not transfer browser-extension data for purposes unrelated to the extension's single purpose.

## 8. Data selling and advertising

HardStop does not sell personal information or browser activity.

HardStop does not use information processed by the extension to display personalized advertisements.

HardStop does not provide website navigation information to third parties for advertising, marketing, credit scoring, or data-broker purposes.

## 9. Remote code and external resources

The HardStop browser extension does not download and execute remotely hosted JavaScript or WebAssembly. Executable extension code is packaged with the extension.

HardStop may receive non-executable information, such as updated gambling-domain rules or configuration data, when required to maintain its blocking functionality. Such information is treated as data and is not executed as remote program code.

## 10. Security

HardStop uses reasonable administrative and technical measures intended to protect information from unauthorized access, alteration, disclosure, or destruction.

These measures may include:

- Limiting extension permissions to functions required by HardStop.
- Processing blocking decisions locally when reasonably possible.
- Restricting native messaging to the authorized HardStop application.
- Limiting information access to legitimate operational needs.
- Reviewing updates for unnecessary permissions or remote code.
- Using secure network connections when information must be transmitted.

No browser extension, application, storage system, or transmission method can be guaranteed to be completely secure. Users should keep their browser, operating system, HardStop extension, and HardStop desktop application updated.

## 11. User choices and control

Depending on the selected protection settings and whether an active lock period exists, users may be able to:

- Review protection status.
- Modify permitted extension settings.
- Clear locally stored browser information.
- Disconnect the HardStop desktop application.
- Uninstall the extension.
- Contact HardStop with a privacy request.

Some settings may be intentionally restricted during a user-selected protection period. These restrictions are part of the blocking service requested by the user and will be described before activation where applicable.

Users may contact us to request information about personal data that HardStop maintains outside their device or to request correction or deletion, subject to identity verification and applicable legal exceptions.
