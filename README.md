# HardStop

HardStop is a Windows application that helps people voluntarily block access to gambling websites and strengthen protection against impulsive gambling.

## Installation

1. Download `HardStop-Setup.exe` from the latest GitHub Release.
2. Optionally verify the installer against the published SHA-256 checksum.
3. Run the installer and follow the HardStop setup flow.
4. Connect Chrome when prompted to enable browser protection.

The current installer is not digitally signed. Windows may display an Unknown Publisher or Microsoft Defender SmartScreen warning.
