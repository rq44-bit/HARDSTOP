HardStop

Browser Blocker Options

Manage extra domains, custom imports, support resources, and privacy settings.

Import Hosts File

Import a plain hosts-style file or one-domain-per-line list. Imported domains are added as custom dynamic browser rules until the browser rule limit is reached.

Aggressive Matching

Aggressive rules block gambling-related domains and gambling-specific TLDs. This can overblock some harmless pages.

Privacy

No browsing history is uploaded by this extension.

Sources

The packaged gambling list is derived from The Block List Project gambling hosts list, MIT license, plus a small curated seed list.
